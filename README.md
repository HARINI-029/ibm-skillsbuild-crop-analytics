# IBM SkillsBuild Data Analytics Internship Project

## 📌 Project Overview
This repository contains the official project submission for the **6-Week Virtual IBM SkillsBuild Data Analytics with AI Internship**, completed in collaboration with **AICTE** and **BharatCares**[cite: 2]. The project focuses on performing an in-depth agricultural data analysis on the **`Crop.csv`** dataset using Python and applying a Business Intelligence (BI) 5-Level Hierarchy framework[cite: 2].

---

## 📂 Repository Contents
* **`Crop_yield_analysis.ipynb`** — The primary Google Colab / Jupyter Notebook containing data inspection, cleaning, BI modeling, and visualizations.
* **`Crop.csv`** — The core agricultural dataset used for the analysis[cite: 2].
* **`requirements.txt`** — The dependency list required to run the environment (`pandas`, `numpy`, `matplotlib`, `seaborn`, `jupyter`).
* **`INTERNSHIP PROJECT REPORT.docx`** — The formal comprehensive project report detailing methodology, output screenshots, findings, and strategic recommendations[cite: 2].

---

## 🏗️ BI 5-Level Framework Implemented
1. **Level 1 (KPIs):** Evaluated macro-level production metrics, average yields, cultivated areas, and rainfall averages[cite: 2].
2. **Level 2 (Trends):** Tracked historical yield progression across crop years using trend visualization[cite: 2].
3. **Level 3 (Drivers):** Analyzed linear relationships and correlations between chemical inputs (fertilizer/pesticide) and environmental factors relative to crop yield[cite: 2].
4. **Level 4 (Risks & Opportunities):** Identified top-performing high-yield crops (e.g., Coconut, Sugarcane) and flagged low-yielding regional risk alerts[cite: 2].
5. **Level 5 (Actions):** Proposed strategic recommendations for resource allocation and climate monitoring[cite: 2].

## 🚀 How to Run the Project
1. Clone this repository or download the project files.
2. Open Jupyter Notebook or Google Colab.
3. Upload `Crop_yield_analysis.ipynb` and `Crop.csv`[cite: 2].
4. Run the notebook cells sequentially from top to bottom.
